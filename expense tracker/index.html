Features

📝 Record expenses

Add date, category, description and amount, with input validation.

💾 File handling

Data is read from and saved to expenses.txt, so it survives closing the program.

📊 Pattern analysis

Category split, monthly trends, daily average and month-end projection.

🚨 Smart alerts

Budget warnings at 80% and when exceeded, plus unusual expense detection.

    How it is built

    Three source files, compiled into a dynamic library by a Makefile, as the project guidelines require.

    1. expense.h declares the functions.
    2. expense.c defines them and becomes libexpense.so.
    3. main.c shows the menu and calls the library.
    make          # builds libexpense.so and tracker
./tracker     # run the program
make clean    # remove generated files
